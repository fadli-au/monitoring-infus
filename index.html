Sistem Monitoring Infus IoT • Nurse Station Real-Time Dashboard • Siap Integrasi ESP32 + Firebase RTDB

Pengaturan Koneksi Firebase RTDB

Hubungkan dashboard ini ke Firebase Realtime Database milikmu agar data dari alat ESP32 maupun tombol simulator langsung tersinkronisasi secara real-time.

Salin URL dari menu Build → Realtime Database di Firebase Console.

Contoh struktur: /infus_nodes/node_01

Catatan Keamanan Pengujian: Pastikan Security Rules di Firebase RTDB mengizinkan baca/tulis (".read": true, ".write": true) selama tahap uji coba purwarupa.

Panduan Arsitektur Sistem & Integrasi ESP32

1. Alur Kerja Sistem IoT (End-to-End)

1. Perangkat Keras (ESP32)

Load Cell (HX711) menimbang sisa cairan (mL) dan Sensor IR menghitung tetesan per menit (DPM).

2. Cloud Broker (Firebase)

ESP32 mengirim data JSON via WiFi ke Firebase RTDB setiap 2–5 detik sebagai jembatan awan.

3. Nurse Station Web

Dashboard mendeteksi anomali, menghitung ETA habis, dan membacakan peringatan via Web Speech API.

2. Format JSON yang Dikirim ESP32 ke Firebase

{
  "infus_nodes": {
    "node_01": {
      "nama": "Kamar 1 - Bed A",
      "sisaCairan": 450,
      "kapasitasAwal": 500,
      "dpm": 20,
      "targetDpm": 20,
      "faktorTetes": 20,
      "updatedAt": 1731859200000
    }
  }
}

3. Logika Penentuan Status Otomatis

Status Kondisi Pemicu Respon Sistem
NORMAL Cairan > 50 mL & 5 ≤ DPM ≤ 35 Pantauan rutin, alarm diam.
WARNING Cairan 16–50 mL atau DPM lambat (< 5) Notifikasi kuning + pengingat suara.
CRITICAL Cairan ≤ 15 mL, Mampet (0 DPM), atau Over-Drip (> 35 DPM) Kartu merah berdenyut + alarm suara prioritas.
OFFLINE Tidak ada pembaruan data > 35 detik Peringatan koneksi alat terputus.
